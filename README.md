# 💬 Real-Time Chat Server

## 📌 Description

A real-time chat application using Socket.IO where users can join chat rooms and exchange messages instantly.

## 🛠 Tech Stack

* Node.js
* Express.js
* Socket.IO

## 🚀 Features

* Real-time messaging
* Multiple chat rooms
* Instant message broadcast

## ▶️ Run Project

npm install
node server.js

## 🌐 Demo

Open index.html in browser and start chatting.
